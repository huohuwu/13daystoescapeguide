How to redeem a code when one appears

We have not confirmed that 13 Days to Escape already has a codes button in the HUD or settings menu. Until we see one in-game, treat the steps below as the usual Roblox pattern, not as a promise that a box is waiting for you today.

  1. Open 13 Days to Escape on Roblox and let the game finish loading.
  2. Look for a Codes, Gift, or similar button — often at the edge of the screen, or inside Settings. If nothing is there, the game may not have added redemption yet.
  3. Type or paste the code exactly as the developer posted it. Codes are usually case-sensitive.
  4. Press Redeem or Enter, then check your cash, inventory, or the message the game shows.

If a code is rejected, check the spelling and spaces first. It may also have expired, already been claimed on your account, or require you to join the developer’s Roblox group. Keep the exact error text if you want us to look into it.

Checked in-game on 13 November 2026: during Day 1 and Day 2 of our run, we did not see a Codes or Redeem button on the game screen. We have not checked the lobby menu yet, so we will update this when we do.

Where new codes will show up first

When RoDark Studios releases a code, it will most likely appear in one of these places:

  • The description on the official Roblox game page
  • The RoDark Studios Roblox group or the social links on the game page
  • An official Discord or other developer announcement

We check those sources regularly. When a verified code is posted, it will be added here with the reward (if known) and the date we confirmed it. Do not trust random “working codes” lists that do not show a source — Roblox also has similarly named games, and a code from a copy will not work here.
